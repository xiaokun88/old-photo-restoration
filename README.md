# 老照片修复

适用于豆包工作及其他能够读取 Agent Skill 的环境。主任务是改善照片可读性，同时让使用者看清哪些细节可能由模型推测而来。默认重点是模糊、低分辨率和人脸；划痕、褪色与上色按照片和用户要求处理。

## 开始前

1. 获取原始图片；若用户尚未提供，先请其上传或给出可访问的路径。保留未修改原件，不覆盖输入文件。
2. 观察分辨率、色彩模式、朝向、人脸数量与大小，以及模糊、噪声、压缩、划痕、缺损或褪色的程度。区分看得见的事实与推测；没有原图参照时，不声称恢复了真实五官或真实颜色。
3. 检查当前环境实际可用的图像工具、Python/Pillow、CPU/GPU、已安装模型及权重。不要假定豆包工作能访问用户本机或有 GPU。仅在可执行时运行修复；否则给出适合该照片的步骤与命令，不虚构图像文件。
4. 原图含家人肖像时，优先本地或当前授权环境处理。上传第三方服务、安装依赖、下载模型或权重前，说明去向、来源和成本，并取得用户同意；已经明确授权的动作无需重复询问。

## 默认修复路径

- **保真版**：保持原有黑白或彩色模式与原始尺寸，只做轻度对比度、噪声或锐度调整。若细节本来无法辨认，应保留不确定性。
- **增强版**：从保真版出发，按需放大和修复人脸。优先比较身份特征、眼镜、发际线、皱纹、衣领、背景文字与边缘；有明显改脸或伪影时，降低强度或退回保真版。黑白上色另行生成并标为推测色彩，不替换黑白结果。
- **工具选择**：普通锐化和放大只能提升观感，不能创造真实细节。可用且适合时，GFPGAN 用于人脸增强，Real-ESRGAN 用于整体放大；划痕严重时再考虑 Microsoft's Bringing Old Photos Back to Life；CodeFormer 可作为人脸保真对照候选，但先核对其专用许可。具体取舍见 [模型与许可](references/models.md)。不要盲目串联全部模型。
- **交付**：原图副本、保真版、增强版、并排对照和简短记录；写明运行过的步骤、模型及版本、未处理的破损、可能被推测的面部细节。若某一步不可用，说明实际产物与缺失原因，不把插值放大称为 AI 人脸修复。

## 可选本地执行

如果环境能运行 Python 和 Pillow，可调用本 Skill 的轻量脚本：

```bash
python scripts/restore.py --input "原图路径" --output-dir "新输出目录"
```

默认运行不联网、不安装依赖，产生原图副本、两种强度、对照图与处理记录。若用户已准备好 GFPGAN 仓库、依赖和 `GFPGANv1.4.pth` 权重，并同意上游程序在需要时下载辅助权重，可加 `--gfpgan-root "仓库路径" --allow-upstream-downloads`；脚本会先检查主权重，再调用上游推理程序。缺少该许可参数时只做轻量增强。脚本输出只是候选结果，必须目视检查人脸身份与伪影。详细参数与上游项目入口见 [模型与许可](references/models.md)。

不要因脚本不可运行而终止指导路径；针对照片给出可执行的人工或工具操作方案即可。
